    What this check does and does not prove

    A passing check means the bytes running in this browser hash to a bundle attested on-chain at a reviewed commit, served by a canister whose module hash independent verifiers reproduced from source. That closes malicious server serves malicious client.

    It does not close a compromised browser or operating system, which reads your choice before any of this runs, and it does not make the reviewed code correct — only identical to what was reviewed. It does not prevent coercion. See THREAT_MODEL.md.
